# दिशा ब्राउज़र (Disha Browser)

हिंदी में बना तेज़ Android ब्राउज़र। APK हर push पर GitHub Actions से अपने आप बनता है — **Releases** में जाकर नई `DishaBrowser-v*.apk` डाउनलोड करें।

## फ़ीचर
- कई टैब, टैब स्विचर, इनकॉग्निटो टैब, बंद टैब फिर खोलें
- डिफ़ॉल्ट सर्च Google + अपना **दिशा सर्च** (विकिपीडिया हिंदी/अंग्रेज़ी परिणाम, सारांश, कैलकुलेटर, तारीख/समय), Bing, DuckDuckGo, Yahoo, YouTube
- दिशा होम पेज: शॉर्टकट, तारीख-समय, आज का विचार
- बुकमार्क, इतिहास, डाउनलोड मैनेजर, ब्राउज़िंग डेटा हटाएँ
- पेज में खोजें, शेयर, हिंदी अनुवाद, रीडिंग मोड, डेस्कटॉप साइट, होम स्क्रीन शॉर्टकट
- वॉइस सर्च (हिंदी), विज्ञापन ब्लॉकर, डार्क मोड, टेक्स्ट साइज़, पुल-टू-रिफ्रेश, फ़ुलस्क्रीन वीडियो, फ़ाइल अपलोड
- रोज़ाना ताज़ा ख़बरों का नोटिफिकेशन और नए वर्ज़न का अपडेट नोटिफिकेशन
- डिफ़ॉल्ट ब्राउज़र के रूप में सेट किया जा सकता है
